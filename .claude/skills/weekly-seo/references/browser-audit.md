# Browser audit of the platform UIs, and MCP health

> Added 2026-10-07. Facts about the world: overwrite when re-verified. Dated numbers are a snapshot; the newest report in seo-reports/ has current values.

Some data exists only in the platform UIs (Search Console coverage, links, crawl stats; GA4 Admin; Clarity AI Visibility and settings; Bing Recommendations and AI Performance). Read it with the `playwright-chrome` MCP, which drives the owner's signed-in Chrome. Read-only by default. The auto-mode classifier **blocks changes to account or analytics settings** (a GA4 data-retention change and a Clarity funnel were both refused on 2026-10-07): leave those to the owner and list them under "Needs a human". Never click `Remove property`, `Disconnect`, `Delete`, or any submit that changes a setting unless the owner asked for that exact action.

Tips that held: run a loop of page visits in one `browser_run_code_unsafe` call and return trimmed `innerText` per page (a call over ~120 s moves to the background and notifies on completion); wait 5-9 s after each navigation; the Rows-per-page dropdown does not respond to scripted clicks, so use the API bundle for full lists.

## MCP servers: health and fixes

- The uv-based MCPs (`mosaic-bing`, `mosaic-ga4`, `mosaic-gsc`) run from `~/.cache/uv/archive-v0/...`. A uv cache clean while they run deletes their environments and breaks them with `No module named 'httpcore'` (Bing) or `cannot import name '_plugin_wrapping' from 'grpc'` (GA4). Fix: relaunch each once so uv rebuilds the environment (run the launcher in `~/.config/mosaic-seo/mcp/` with stdin closed), then `/mcp` reconnect. If it recurs, find what runs the cache clean.
- `mosaic-ga4`: the Data API works; **Admin-API tools (property details, annotations, custom definitions) fail with `SERVICE_DISABLED`** until the owner enables `analyticsadmin.googleapis.com` on the Google Cloud project behind the service account.
- `mosaic-gsc` returns an authentication error (no OAuth, no credentials path configured); use the service-account scripts (`gsc-extract.py`, `gsc-sitemap-submit.py`) instead.
- `mosaic-gbp`: see `gbp.md` (reply endpoint patched; reconnect to load it).
- `mosaic-clarity` was not exercised this run; the Clarity extractor is unaffected.
