### Needs verification before it can be ranked

Console errors on 4/8 pages reference GA4 and `stats.g.doubleclick.net` collect endpoints, plus one unidentified 404. The CSP `connect-src` allows `analytics.google.com`, `*.google-analytics.com`, `www.googletagmanager.com` and `www.google.com`, but **not** `stats.g.doubleclick.net`. If those requests are being blocked, GA4 data would be incomplete — which matters because GA4 is one of this workflow's own inputs. Lighthouse truncated the error text, so the causal link is not proven. Next run should capture the full console output before any CSP change is proposed. Do not edit the CSP on this evidence alone.
